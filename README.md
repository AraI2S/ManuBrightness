# ManuBrightness

**Windows 软件亮度快捷键工具**。通过 Windows Gamma Ramp 调节桌面输出的明暗曲线，支持日常和影视两种模式、全局快捷键、亮度记忆与参数自动恢复。项目提供完整可编辑源码，**无需安装 AutoHotkey、Python、PowerShell 7 或其他第三方运行环境**。

当前版本：**v7.0.2（Windows 原生源码版，测试迭代）**。

## 运行条件与启动

- Windows 10/11，带有 Windows PowerShell 5.1 与 .NET Framework 的常规个人电脑。
- 适用显示器/显卡驱动需要支持 Windows `GetDeviceGammaRamp` / `SetDeviceGammaRamp`；不同驱动、HDR 和多显示器配置可能存在兼容性差异。
- 下载并解压整个项目，让 `Main.cmd` 和 `ManuBrightness.ps1` 保持在同一目录；**双击 `Main.cmd` 启动**。
- 启动窗口会很快关闭，程序留在系统托盘。右键托盘图标可刷新、暂停、切换模式或退出。
- 请先退出已有 ManuBrightness / 旧 AutoHotkey 版本，避免抢占同一组热键和显示参数。

`Main.cmd` 只是调用 Windows 内置 PowerShell 的启动入口；程序源码位于 `ManuBrightness.ps1`，其中包含以文本形式嵌入、启动时在内存中编译的 C# 代码。程序不会产生额外的 EXE，也无需安装编译器或持久修改 PowerShell 执行策略；脚本策略仅针对本次启动的进程。受组织管理的电脑可能禁止脚本执行或动态代码编译。

首次运行后，程序在相同目录写入 `ManuBrightness.ini` 保存亮度。若检测到旧 `GpuBrightness.ini`，可迁移旧日常亮度；`GpuBrightness.ini` 本身不会被覆盖。**INI 文件是运行时个人配置，适合加入 `.gitignore`，无需随 GitHub 源码分发。**

## 快捷键

- `Alt` + 数字小键盘 `+`：提高当前模式亮度（每次 +50）
- `Alt` + 数字小键盘 `-`：降低当前模式亮度（每次 -50）
- `Alt` + 数字小键盘 `*`：重新应用当前亮度映射
- `Alt` + 数字小键盘 `/`：临时暂停当前亮度映射
- `Alt` + 主键盘 `=`：切换**日常 / 影视**模式

日常与影视模式分别记住最后使用的亮度。程序启动时进入日常模式；首次进入影视模式的默认亮度为 600。按调亮、调暗、手动刷新或切换模式会退出暂停状态。关闭程序时保留当时的画面映射，若想恢复线性 Gamma Ramp，可先执行暂停操作。

## 工作原理

ManuBrightness 使用 Windows GDI API 写入 **RGB 三通道、每通道 256 项、每项 16 位**的 Gamma Ramp，调整的是显示信号映射，而非显示器物理背光功率。

- **日常模式**：控制值 0–1000，常用区间 200–800 采用均匀映射，极暗/极亮区间采用不同形状的曲线。输出通过原有 Gamma、Gain、Lift 数学公式生成。
- **影视模式**：采用独立的幂函数与深黑位保护区，让较暗区域更容易辨识，同时尽量保留黑位与高亮层次。
- **自动恢复**：非暂停状态每 1 秒读取当前 Gamma Ramp；任意一项与目标数值相差超过 **255** 时重新写入；每 30 秒无条件补写一次以应对无法可靠读回的系统覆盖。暂停时停止检测与补写。
- **HiDPI**：v7.0.2 在生成托盘菜单和亮度提示窗口之前启用 Per-Monitor V2 DPI awareness，减少 4K / 高缩放下的模糊文字；在不能启用时使用兼容性回退。

Windows、显示驱动、HDR / ICC 色彩管理可能覆盖或限制 Gamma Ramp；在 HDR 模式下，这些老 API 的行为没有充分保证。强提亮还可能抬黑、削掉高光。**对所有电脑都保证相同视觉效果超出本项目目前的支持范围。**

## 版本记录

版本号遵循 **大版本.小版本.测试迭代**：重大重构升级第一位；小功能成功验收后升级第二位；未验收的试验/调试版本递增第三位。早期研发时期未统一三段命名，下列名称依据后来保存的历史版本归档整理；配置中的 `MapVersion` 是亮度映射数据兼容标记，与项目版本号不同。

### Windows 原生源码阶段

- **v7.0.2（当前，待实机验收）**：针对 4K 和 Windows 高 DPI 缩放下模糊的弹窗/托盘菜单，初始化 Per-Monitor V2 DPI 感知，改善提示框布局；开始在每一新版维护本 README。亮度与热键算法保持不变。
- **v7.0.1**：修复 Windows Terminal 作为默认终端时，PowerShell 常驻窗口无法隐藏的问题；启动器通过独立无控制台后台进程运行，关闭启动窗口不会终止托盘程序。
- **v7.0.0**：将 AHK 运行架构移植为 Windows PowerShell 5.1 + 内嵌 C#，源码公开，直接调用 Windows API；保留两套模式、热键、配置迁移与 Gamma Ramp 自动恢复。

### AutoHotkey 历史阶段

- **v6.1.3（经用户确认可用）**：在每秒 Gamma Ramp 监测中，将单项容差调整为 255；保留每 30 秒的兜底补写。
- **v6.1.2（当时曾以 v6.2 发布的试验版）**：将 Gamma Ramp 检测改为严格相等，后续发现可能因驱动精度造成不必要的反复补写。
- **v6.1.1（当时曾以 v6.1 发布）**：增加每秒读取 Gamma Ramp 并检测系统覆盖、每 30 秒补写以及暂停时停止监测；初版单项容差 512。
- **v6.0**：增加「日常 / 影视」双模式及 `Alt+=`；影视模式使用独立曲线保护深黑，两个模式分别保存亮度。
- **v5.1**：项目统一命名为 ManuBrightness，延续成熟的日常亮度曲线。
- **v5.0**：保留日常 200–800 平滑映射、强高亮端，将热键步长由 40 调整为 50。
- **v4.x（试验阶段，原始文件未完整留存）**：常用区间平滑映射；使用 Hermite 曲线过渡极端区间，但高亮端灵敏度不足，随后优化。
- **v3.x（试验阶段，原始文件未完整留存）**：尝试将新控制值 200–800 对齐旧控制值 400–960；发现旧版高亮拐点也被带入日常区间。
- **v2.1**：常用区间工作版，热键步长变为 40，增加 `Alt + 小键盘 /` 临时暂停映射。
- **v2.0**：首次加入常用区间重映射，控制值 100–900 对应原有效视觉值 200–600；增加手动刷新，步长 25。
- **v1.0**：最初的 AutoHotkey v2 Gamma Ramp 热键脚本，直接通过 0–1000 控制明暗；步长 25，提供小键盘加减快捷键。
